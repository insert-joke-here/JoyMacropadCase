# JoyMacropadCase

a case for the macropad [here:](https://github.com/insert-joke-here/JoystickMacropad)
<img width="1365" height="547" alt="the repo" src="https://github.com/user-attachments/assets/e6bb539c-1388-457a-8465-31db9cba57c3" />


It's a case for a 2x3 macropad with a joystick that you can plug into your computer and use.

The cad is designed in two parts: one for the base on which the pcb rests, and one for the top. The pcb goes on top of the base, and the feather devboard im using hangs down from underneath and rests on the ground, while being soldered to the pcb. The top goes over everything, with holes for the keys and for the joystick so that they can be used.

It uses M6 screws to hold everything together, 4 for the top and bottom and another four to hold the joystick in place. There are none for the pcb, as it is designed to fall in place into the slot on the base instead of being screwed, to allow me to more easily(-ish?) take it out if there's a problem, as well as providing a little more tolerance for my design. (The joystick's screws should help hold the pcb in place too, so it shouldn't slide _too_ much.

It isn't angled, because I thought an angle wouldn't make it any more comfortable to use with the joystick.
