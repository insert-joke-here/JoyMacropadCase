# JoyMacropadCase

a case for the macropad [here:](https://github.com/insert-joke-here/JoystickMacropad)
<img width="1365" height="547" alt="the repo" src="https://github.com/user-attachments/assets/e6bb539c-1388-457a-8465-31db9cba57c3" />


It's a case for a 2x3 macropad with a joystick that you can plug into your computer and use.

The cad is designed in two parts: one for the base on which the pcb rests, and one for the top. It isn't angled, because I thought an angle wouldn't make it any more comfortable. 

<img width="711" height="505" alt="image" src="https://github.com/user-attachments/assets/36249d24-7118-4a34-bedc-5fbe34177e72" />

It uses M6 screws to hold everything together, 4 for the top and bottom and another four to hold the joystick in place. There are none for the pcb, as it is designed to fall in place into the slot on the base instead of being screwed, to allow me to more easily(-ish?) take it out if there's a problem. (The joystick's screws help hold it in place too, so it doesnt slide _too_ much.

(Yes, I'm aware it's just a box.)
